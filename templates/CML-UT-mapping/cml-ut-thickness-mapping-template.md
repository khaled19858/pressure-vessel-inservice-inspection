SECTION 10 -- CORROSION RATE CALCULATION
--------------------------------------------------------------------------------

Method
------
Short-term corrosion rate (CR_ST): based on last two consecutive readings.
Long-term corrosion rate (CR_LT) : based on first and last readings.
Design corrosion rate (CR_D)     : more conservative of CR_ST and CR_LT,
                                   unless engineering judgment justifies
                                   otherwise (document basis).

Formulas
--------
CR_ST = (t_prior - t_current) / delta_t_ST     [mpy or mm/yr]
CR_LT = (t_initial - t_current) / delta_t_LT   [mpy or mm/yr]

where:
  t_initial  = nominal / baseline thickness at CML (in or mm)
  t_prior    = thickness at prior inspection (in or mm)
  t_current  = thickness at current inspection (in or mm)
  delta_t_ST = elapsed time between t_prior and t_current (years)
  delta_t_LT = elapsed time between t_initial and t_current (years)

Use minimum thickness readings for rate calculations.

SECTION 11 -- REQUIRED THICKNESS REFERENCE
--------------------------------------------------------------------------------

The required thickness (t_req) at each CML is governed by the design code
applicable to the component. These values must be established from the vessel
design calculations or by calculation by a qualified engineer. Do not estimate.

Required thicknesses shall account for:
  - Design pressure and MAWP
  - Static head contribution (per CLAUDE.md orientation rule)
  - Applicable code formula for the component geometry
  - Applicable joint efficiency (E)
  - Applicable allowable stress (S) at design temperature
  - Corrosion allowance is NOT included in t_req; t_req is the minimum
    required structural thickness, net of CA

| CML ID   | Component      | Code Formula Reference                    | S (psi/MPa) | E    | t_req (in/mm) | CA (in/mm) | t_min = t_req + CA (in/mm) | Source / Rev |
|----------|----------------|-------------------------------------------|-------------|------|---------------|------------|----------------------------|--------------|
|          |                |                                           |             |      |               |            |                            |              |
|          |                |                                           |             |      |               |            |                            |              |
|          |                |                                           |             |      |               |            |                            |              |
|          |                |                                           |             |      |               |            |                            |              |

t_min = t_req + CA is the minimum acceptable remaining thickness for
continued operation without rerate or repair.

If t_min is not available from design records, it shall be calculated before
retirement thickness and remaining life calculations are completed.

SECTION 12 -- RETIREMENT THICKNESS
--------------------------------------------------------------------------------

The retirement thickness (t_ret) is the minimum measured thickness below which
the component shall be removed from service, repaired, or rerated.

t_ret = t_req  (retirement at loss of structural adequacy, no future CA)

Alternatively, where future corrosion allowance (FCA) is specified by the
inspection plan:

t_ret = t_req + FCA

SECTION 14 -- LOCAL THIN AREAS (LTA)
--------------------------------------------------------------------------------

A local thin area is a region where the measured minimum thickness is less
than the nominal minus acceptable general metal loss, but may or may not be
below t_ret. LTAs require evaluation per FFS methods (e.g., API 579 Part 5)
if they are below t_min or exhibit a circumferential or axial extent requiring
assessment.
